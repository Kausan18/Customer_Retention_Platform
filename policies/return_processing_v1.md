# Return Processing

Version: 1.0 | Effective: 2026-01-01  
**Document ID:** return_processing_v1

## Overview

This policy explains how a return is received, inspected, and resolved after a customer sends an item back. The store logs the return when it arrives, then inspects it before resolving the request.

## Eligibility Conditions

A return is considered received when the store logs its arrival.
Inspection is completed within 3 to 5 business days of receipt.
An inspection passes when the item is undamaged and complete.

## Process

1. The return request is recorded and return logistics are arranged with the customer.
2. The returned item is received and its receipt is recorded.
3. Inspection is completed within 3–5 business days after receipt.
4. The inspection result is recorded and communicated to the customer.

An inspection passes when the item is undamaged and complete. It fails if the item is damaged or incomplete; the inspection record should state the reason.

## Exceptions

If inspection fails, the customer is told what condition was not met and why. The return is not treated as an approved refund or exchange solely because the item was sent back; the customer is informed of the next review or resolution step applicable to their request.
